# My Expense Analyzer

A complete Kotlin + Jetpack Compose + Material 3 Android expense manager with offline Room persistence, MVVM, transaction history, monthly analysis, category charts, month comparison, settings, and CSV sharing.

## Requirements
- Android Studio Quail 4 (2026.1.4) or newer
- JDK 17
- Android SDK Platform 37

Minimum Android version: API 26.
